# «Последний поезд» — правила для Claude

Браузерная игра: колония в духе RimWorld на магическом поезде. Чистый JS (ES-модули) + Canvas 2D + Web Audio, без зависимостей и сборщика.

## Где что
- `PLAN.md` — дизайн игры (раздел 14 — границы контента, обязателен; раздел 16 — механики [v1]/[позже]).
- `docs/ARCHITECTURE.md` — контракт ядра для модулей (реестры, game.api, события, клавиши, сохранения). Источник истины.
- `docs/specs/mvp-*.md` — короткие задания текущего этапа (MVP). `docs/specs/<модуль>.md` — полные задания на потом.
- `PROGRESS.md` — что сделано и какой следующий шаг. Читать первым, обновлять в конце каждой работы.
- Код: ядро `js/core|engine|sim|render|player|ai`, модули `js/modules/<имя>/` (вход — `index.js` с `register(game)`).

## Команды
- Тест симуляции: `node tests/headless.mjs --days 10 --seed 1` (+ сиды 2, 3)
- Тест контракта: `node tests/contract.mjs`
- Браузерный тест: `node tests/browser.mjs` (Playwright: `/opt/node22/lib/node_modules/playwright`, браузеры `/opt/pw-browsers`; скриншоты в `tests/screens/`, они в .gitignore)
- Локально поиграть: `node tests/server.mjs` → http://localhost:8080

## Правила работы
- **Режим MVP:** делать только то, что в `docs/specs/mvp-*.md` текущего шага. Всё лишнее — не делать, а записать в PROGRESS.md в «После MVP».
- Шаги запускаются только по команде пользователя (автозапуск выключен).
- Экономия лимита: **не больше одного субагента одновременно**. Никаких параллельных флотов агентов, никаких workflow/ultracode.
- Модуль правит только свою папку `js/modules/<имя>/` (+ свои тесты `tests/<имя>*.mjs`); межмодульные вызовы — только через `game.api.<ns>.<fn>`.
- Новые клавиши — сначала в `js/core/keymap.js`. Пробел — пауза, Shift — рывок.
- Детерминизм: в симуляции только `game.rng`, не `Math.random`. В `register()` нельзя трогать DOM.
- Все тексты — через i18n, ru и en.
- Перед коммитом все три теста должны проходить.
- Ветка: `claude/keen-fermat-b06xcc`. Коммиты по-русски. Pull Request в `main` — только когда игра играбельна и пользователь согласен.
