# MVP-5. Интерфейс: минимум

В `js/modules/ui/` есть черновики (`kit.js` — виджеты, `scenes.js` — фон меню, `util.js`, `state.js`), `index.js` — заглушка.

## Сделать
1. Главное меню: «Новая игра», «Продолжить», «Загрузить», «Настройки», анимированный фон (поезд ночью).
2. Новая игра: имя колонии, имя лидера, сид, сложность → `game.newGame(opts)` со сценарием `three_survivors`.
3. Пауза Esc: продолжить, сохранить, загрузить, настройки, выйти в меню. Автосохранение по прибытии на станцию.
4. Настройки: язык RU/EN, громкость, «Грубая речь», тряска экрана.
5. Экран конца игры (`colony:lost`): статистика и список павших. Экран победы (`game:victory`).
6. Обучение: 5–6 подсказок на первой станции (WASD, рубить E, построить кровать B, призыв R, гудок H, карта F4). Можно отключить.
7. Не ломать уже существующие панели модулей (F2, F8, бой).

## Не делать (после MVP)
Перрон отбора, настройка внешности, переназначение клавиш, полировка всех панелей, журнал F3 и работы F1, если не помещаются.

## Готово, когда
Все тесты зелёные + `ui.test`. В браузере: меню → новая игра → игра → Esc → сохранить → выйти → загрузить.
