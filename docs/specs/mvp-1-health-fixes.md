# MVP-1. Здоровье: критичные исправления

Модуль `js/modules/health/` уже подключён (см. журнал в PROGRESS.md). Тестировщик нашёл ошибки. Чинить ТОЛЬКО это (можно минимально трогать `js/modules/combat/` и `tests/combat.test.mjs`).

## Сделать
1. Удержание E на упавшем = переноска; короткое нажатие = перевязка (`care.js`: `health:tend` order 6 перехватывает `health:carry` order 7).
2. Мгновенная смерть — только от разрушения мозга или сердца. Туловище и шея → сильное кровотечение / «упал» / «последнее дыхание» (`defs.js:12,22`, `model.js:262`).
3. Поддержать `opts.lethal` в `applyDamage` (combat должен передавать его, `fight.js:573`); урон сверх отсечённой части не теряется (`model.js:476-480`).
4. Лежачего не добивает любой удар: порог «≥2× оставшегося» от `h.hp≈0` заменить разумным; причина смерти — реальный удар (`model.js:495,561`).
5. Узел `health:emergency` прерывает бой у поселенца с включённой работой врача, если рядом кто-то истекает кровью, а сам он не в ближнем бою.
6. Удар ≥10 роняет и несомое тело (`carryCorpseId`, `model.js:546`).
7. Таймер «последнего дыхания» замирает, пока врач/лидер перевязывает (`death.js:332`).
8. `tests/combat.test.mjs` (сейчас 116/9): класть пешек через настоящий API здоровья, а не `p.downed=true`/`health.hp=N`. Все проверки зелёные.
