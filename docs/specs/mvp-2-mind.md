# MVP-2. Разум поселенцев: минимум

В `js/modules/mind/` уже есть данные (`defs/`, `strings/`) и черновик движка (`core/`: mood, needs, skills, relations, bio, traits, env, ctx). `index.js` — заглушка. Подключить и довести до минимума.

## Сделать
1. Потребности: еда, сон, отдых, комфорт, общение — падают со временем, пешки идут их удовлетворять (используя то, что есть в ядре: еда, кровати, столы).
2. Мысли: реестр, `game.api.mind.addThought(pawn, id, opts)`; 10–15 мыслей (поел за столом / на полу, спал в кровати / на земле, видел труп, друг погиб — их шлёт health, проверить, что id совпадают; мысли от combat).
3. Настроение 0–100 из мыслей; при низком — простой срыв (бродит / плачет / прячется), потом восстановление.
4. Черты (используются уже написанные), влияют числами.
5. Навыки: `getSkill`, `gainXp` (их уже зовут combat и health).
6. Биографии: имя, возраст, предыстория, последние слова — `getBio` (зовёт health).
7. Разговоры: пешки рядом иногда беседуют — поворачиваются друг к другу, над ними пузырь со значком темы; изредка ссора (красный пузырь).
8. `getSheet(pawn)` для будущей карточки персонажа; `getAuthority/addAuthority/willObey` — простые.

## Не делать (после MVP)
Романтика и свадьбы, глубокие отношения, вдохновения, подслушанные разговоры рядом с лидером, скрытые черты, панели I/F7 (если не помещаются).

## Готово, когда
Все тесты зелёные (headless сиды 1–3 `--days 20`, contract, browser, `combat.test`, `health.test`, новый `mind.test`). В браузере видны пузыри разговоров, настроение меняется.
