# Последний поезд

Браузерная игра про колонию на магическом поезде, в духе RimWorld, в неоновом стиле. Мир съедает Гниль, а последний
поезд везёт горстку выживших через лес и пепельную пустошь. Вы играете за лидера, мага-проводника. На стоянках
добываете уголь, строите и отбиваетесь от набегов, потом даёте гудок, сажаете людей и едете дальше, пока Гниль
не догнала. Маршрут проходит 4 станции, на последней ждёт Костяной дракон.

Сыграть: **https://romantvl.github.io/AmazingGame/**

Игра написана на чистом JavaScript (ES-модули) с Canvas 2D и Web Audio. Зависимостей и сборки нет.

## Как играть

1. Главное меню → «Новая игра»: название колонии, имя лидера, сид, сложность → «В путь!». Старт — «Трое выживших».
2. На станции: рубите лес и добывайте уголь (E или пометка C), ставьте постройки (B), защищайте людей. В углу —
   подсказки обучения.
3. Карта маршрута (F4): выберите следующую станцию из двух вариантов (лес, деревня, пустошь, руины).
4. Встаньте в кабину локомотива и нажмите H. Начнётся посадка (30 с), потом поезд отправится. Кто не сел,
   останется на станции. Угля должно хватить на перегон, иначе будет дикая стоянка посреди пути.
5. Таймер Гнили в верхней панели показывает, сколько ещё можно стоять на станции.
6. Станция 4 — бой с Костяным драконом. Победа над ним — победа в игре. Если погибнут все, игра закончится.

Сохранение: Esc → «Сохранить» (3 ячейки). При каждом прибытии на станцию игра сохраняется сама.
Загрузка — из паузы или из главного меню («Продолжить» загружает последний сейв).

## Управление

| Действие | Ввод |
|---|---|
| Движение лидера | WASD (камера следует), колесо мыши — зум |
| Атака и заклинания | ЛКМ — посох, 1–4 — заклинания, левый Shift — рывок |
| Действие руками | E: рубить, добывать, строить, лечить, лечь спать; удержание — нести |
| Пометить рубку и добычу | C + мышь |
| «К оружию!» и боевой режим | R — поселенцы рядом встают на защиту, ещё раз R — «Отбой»; F — боевой режим наведённого поселенца |
| Стройка | B — меню, G — поворот, Z — зоны складов, X — снести или снять пометки, ПКМ — отмена |
| Поезд | H в кабине: нажать — посадка, удержать — ехать сейчас, двойное нажатие — «К оружию!» |
| Карта маршрута | F4 |
| Здоровье и павшие | F2, F8 |
| Время | Пробел — пауза, + и − или Num1–3 — скорость |
| Меню и пауза | Esc |
| Отладка | F9 |

Полная раскладка с клавишами на будущее лежит в `js/core/keymap.js`, дизайн игры — в `PLAN.md`.

## Запуск локально

Нужен Node.js 18 или новее.

```sh
node tests/server.mjs          # затем открыть http://localhost:8080
```

Если открыть `index.html` двойным щелчком, игра не запустится: браузеры не грузят ES-модули по `file://`.

Параметры адреса для отладки: `?seed=42&difficulty=hard` запускает игру сразу, без меню. `?menu` показывает
меню всегда.

## Тесты

```sh
node tests/headless.mjs --days 20 --seed 1   # симуляция без браузера (также сиды 2 и 3)
node tests/contract.mjs                      # контракт ядра и модулей
node tests/browser.mjs                       # браузер (Playwright)
node tests/playthrough.mjs                   # полное прохождение: меню → 4 станции → дракон → победа и конец игры
node tests/<модуль>.test.mjs                 # тесты модулей (build, combat, health, journey, mind, train, ui)
node tests/<модуль>.browser.mjs              # браузерные тесты модулей
```

Браузерным тестам нужен Playwright с Chromium. Скриншоты сохраняются в `tests/screens/`.

## Публикация

GitHub Actions (`.github/workflows/pages.yml`) запускает headless-тесты и тест контракта на каждый push.
При push в `main` сайт (`index.html`, `css`, `js`) публикуется на GitHub Pages. Один раз нужно включить:
**Settings → Pages → Source: GitHub Actions**.

## Устройство

- `js/core`, `js/engine`, `js/sim`, `js/render`, `js/player`, `js/ai` — ядро: цикл, ввод, карта, поселенцы, работы,
  отрисовка, сохранения.
- `js/modules/<имя>/` — модули: ui, build, combat, health, mind, train, journey, av, vision, economy.
- `docs/ARCHITECTURE.md` — контракт ядра для модулей. `PROGRESS.md` — что сделано и что дальше.
